# الدينامو — نظام الإدارة الأكاديمية الشامل

تطبيق **سطح مكتب لويندوز** يعمل بقاعدة بيانات محلية على جهازك، بلا إنترنت
وبلا خادم وبلا حساب. مقسّم إلى أربع وحدات تغطي إدارة دورات اللغات من الألف
إلى الياء.

## ⬇️ التحميل

**[تحميل ملف التثبيت لويندوز (64-بت)](https://github.com/almarar88/ideashelf2/releases/latest/download/Dynamo-Setup-1.0.0.exe)**

أو من [صفحة الإصدارات](https://github.com/almarar88/ideashelf2/releases/latest) لاختيار إصدار محدد.

بعد التنزيل: شغّل `Dynamo-Setup-1.0.0.exe` واتبع خطوات التثبيت (يُثبَّت للمستخدم
الحالي بلا صلاحيات مدير)، ثم افتح **الدينامو** من قائمة ابدأ أو من أيقونة سطح المكتب.

> ملاحظة: ويندوز قد يُظهر تنبيه «SmartScreen» لأن ملف التثبيت غير موقّع رقميًا —
> اختر «مزيد من المعلومات» ثم «تشغيل على أي حال».

## الوحدات

### ١ · إدارة دورات اللغات والمدربين

| الأداة | ماذا تفعل |
|---|---|
| **سجل المدربين** | ملف لكل مدرب: التخصص اللغوي (إنجليزي، فرنسي، روسي، أوردو، صيني)، أوقات الفراغ الأسبوعية، المناهج التي يدرّسها، نوع التعاقد وبيانات التواصل. |
| **منسق المستويات** | خطة كل دورة: اللغة والمستوى، المدرب، القاعة، تاريخا البداية والنهاية، الطاقة الاستيعابية، والحصص الأسبوعية (اليوم + وقت البداية والنهاية). |
| **كاشف التعارض** | يُنبّه **باللون الأحمر** فورًا إذا وُضع درسان في نفس القاعة والوقت، أو إذا كان لدى المدرب دورتان متزامنتان — أثناء الكتابة في النموذج وقبل الحفظ، وفي الجدول الأسبوعي، وفي لوحة المؤشرات. ويُنبّه **بالبرتقالي** إذا كان الموعد خارج أوقات فراغ المدرب المسجّلة أو في قاعة تحت الصيانة. |

طريقة الكشف: تُحوَّل كل الدورات والحجوزات إلى «كتل إشغال» موحّدة (يوم +
فترة زمنية + مدى تاريخي)، ثم تُقارن زوجيًا؛ يقع التعارض عندما تتقاطع
الفترتان الزمنيتان **و** المدَيان التاريخيان في نفس اليوم الأسبوعي مع
اشتراك القاعة أو المدرب.

### ٢ · لوجستيات التدريب والشركاء الخارجيين

- **سجل الشركاء**: كل جهة (معهد، مركز ثقافي، جهة أكاديمية…) في ملف واحد، وتحته
  عروض الأسعار والحقائب التدريبية واتفاقيات الشراكة والملفات التعريفية —
  برقم مرجع وتاريخ إصدار وسريان، مع إمكانية إرفاق الملف الأصلي (PDF/Word/Excel/صورة)
  الذي يُنسخ إلى مجلد بيانات التطبيق فلا يضيع لو نُقل الأصل.
- **مدير القاعات والمرافق**: قائمة القاعات وسعتها وتجهيزاتها وحالتها، وشاشة
  «إشغال اليوم» التي تُظهر فورًا أي قاعة مشغولة وأيها فاضية (تدمج حصص الدورات
  مع حجوزات الجهات الخارجية)، وتسجيل طلبات الاستئجار مع فحص تعارض تلقائي قبل الحفظ.

### ٣ · مولّد التقارير والإحصائيات الأكاديمية

- **استيراد البيانات**: اسحب ملف إكسل (`.xlsx` / `.csv`) لبيانات التسجيل أو
  الحضور، والنظام يتعرّف تلقائيًا على نوعه وعلى أعمدته (اسم الطالب، الرقم،
  الدورة، المستوى، التاريخ، حالة الحضور…) بأسماء عربية أو إنجليزية، ويطابق
  الطلبة والدورات الموجودة، ويعرض معاينة قبل التنفيذ. تُقبل التواريخ بصيغتي
  `YYYY-MM-DD` و`DD/MM/YYYY`، وحالات الحضور بصيغ متعددة (حاضر/حضور/present…).
- **تقارير أكاديمية صافية بصيغة PDF**: أعداد المسجلين، نسب الحضور والغياب،
  توزيع الطلبة على المستويات، الإحصاء حسب اللغة، إحصائيات المدربين، إشغال
  القاعات، حالة الدورات، والجدول الأسبوعي — مع فلاتر للفترة واللغة والمستوى
  والمدرب، وإمكانية اختيار الأقسام المطلوبة فقط. ويمكن التصدير كذلك إلى Excel.
- **فلتر الأرقام**: كل تقرير يمرّ إلزاميًا عبر مُنقٍّ يحذف أي عمود أو قيمة ذات
  طابع مالي (أسعار، تكاليف، رسوم، مبالغ، هوامش، أرباح، رواتب، عملات…) بالعربية
  والإنجليزية، ويكتب في تذييل التقرير عدد ما استُبعد. والفلتر نفسه يعمل عند
  **بوابة الاستيراد**: أي عمود مالي في ملف الإكسل يُسقَط قبل دخوله قاعدة
  البيانات أصلًا. النتيجة: تقرير جاهز للرفع للإدارة الأكاديمية دون تنظيف يدوي.

### ٤ · أرشفة محاضر الاجتماعات وتصميم المناهج

- **نموذج المحضر السريع**: تاريخ الاجتماع، الأطراف، الحضور، جدول الأعمال،
  النقاط المتفق عليها، ملاحظات تصميم المنهج، والمتابعة — مع ربط المحضر بمدرب
  أو أكثر، ووسوم، ومرفقات.
- **البحث الفوري**: اكتب اسم مدرب في شريط البحث لتظهر كل المحاضر والمراسلات
  المرتبطة به لحظيًا. البحث يعتمد على **تطبيع النص العربي** (توحيد الهمزات
  والألف المقصورة والتاء المربوطة، وتجاهل التشكيل والأرقام الهندية)، فيجد
  «مريم الانصاري» عند كتابة «مريم الأنصارى».

## تحسينات إضافية مضمّنة

- **لوحة مؤشرات** بإحصاءات حيّة ورسوم (الدورات حسب اللغة، الطلبة حسب المستوى،
  حالة الدورات، إشغال القاعات، متوسط الحضور) — بألوان مُختبَرة للتباين ولعمى الألوان.
- **بحث شامل بضغطة `Ctrl + K`** عبر كل الوحدات (مدربون، دورات، محاضر، شركاء، طلبة، قاعات).
- **رصد الحضور اليومي** بضغطة واحدة لكل طالب، أو «تعليم الجميع حاضر/غائب».
- **وضع داكن وفاتح**، وواجهة عربية كاملة من اليمين لليسار.
- **نسخ احتياطي**: نسخة تلقائية يومية عند التشغيل (يُحتفظ بآخر ٢٠ نسخة)، ونسخ
  يدوي، وتصدير إلى ملف، واستعادة آمنة (تحفظ نسخة من الوضع الحالي قبل الاستبدال).
- **بيانات تجريبية** تُزرع عند أول تشغيل (٦ مدربين، ١٠ دورات، ٦ قاعات، ٤٨ طالبًا،
  سجلات حضور، شركاء، حجوزات، ومحاضر) ويمكن تفريغها بالكامل من الإعدادات.
- **سجل عمليات** يوثّق آخر ما جرى في النظام.

## التشغيل والبناء

المتطلبات: [Node.js 22](https://nodejs.org) أو أحدث. **لا يحتاج التطبيق إلى أي
أدوات ترجمة C++** لأن قاعدة البيانات تستخدم وحدة `node:sqlite` المدمجة في
Electron بدلًا من وحدة أصلية.

```bash
cd mbzuh
npm install

npm run dev          # تشغيل في وضع التطوير
npm run typecheck    # فحص الأنواع
npm run build        # بناء ملفات الإنتاج
```

### إنتاج ملف التثبيت لويندوز

```bash
npm run dist:win     # ينتج release/Dynamo-Setup-1.0.0.exe  (يُنفَّذ على ويندوز)
npm run dist:win:zip # ينتج حزمة مضغوطة تعمل بلا تثبيت (تُبنى من أي نظام)
```

- `dist:win` (مُثبِّت NSIS) يحتاج إلى **ويندوز**، أو إلى `wine` مع دعم 32-بت على لينكس.
- `dist:win:zip` يعمل من أي نظام تشغيل (لينكس/ماك/ويندوز) وينتج مجلدًا كاملًا
  يعمل على ويندوز بمجرد فك الضغط وتشغيل `Dynamo.exe`.
- يوجد سير عمل جاهز على GitHub Actions في
  `.github/workflows/dynamo-windows.yml` يبني ملف التثبيت على `windows-latest`
  ويرفعه كمُخرَج (Artifact) — شغّله يدويًا من تبويب Actions، أو ادفع وسمًا
  باسم `dynamo-v1.0.0` ليُرفق الملف تلقائيًا بإصدار GitHub.

## أين تُحفظ البيانات؟

كل شيء محلي على جهازك:

| المسار (ويندوز) | المحتوى |
|---|---|
| `%APPDATA%\Dynamo\dynamo.db` | قاعدة البيانات (SQLite) |
| `%APPDATA%\Dynamo\backups\` | النسخ الاحتياطية |
| `%APPDATA%\Dynamo\files\` | مرفقات الشركاء والمحاضر |

لا يرسل التطبيق أي بيانات إلى أي خادم، ولا يفتح أي اتصال بالشبكة.

## البنية التقنية

```
mbzuh/
├─ electron/            العملية الرئيسية
│  ├─ db/               الاتصال بقاعدة البيانات + المخطط + البيانات التجريبية
│  ├─ services/         كاشف التعارض · التقارير · فلتر الأرقام · استيراد إكسل · PDF
│  └─ ipc/              قنوات الاتصال مع الواجهة (٤ ملفات حسب الوحدات)
├─ shared/              أنواع وأدوات مشتركة (تطبيع النص العربي، الأوقات، المسميات)
├─ src/                 واجهة React + Tailwind (١٠ شاشات)
└─ build/               أيقونة التطبيق
```

- **Electron 38** + **React 19** + **TypeScript** + **Vite 7** + **Tailwind CSS 4**
- قاعدة البيانات: **SQLite** عبر `node:sqlite` (بلا وحدات أصلية)
- الإكسل: **ExcelJS** · الـPDF: محرك الطباعة المدمج في Electron (دعم كامل للعربية)
- أمان الواجهة: `contextIsolation` مُفعّل، بلا `nodeIntegration`، وجسر IPC
  محصور بقائمة قنوات مسموح بها، ومنع أي تنقّل خارجي داخل النافذة.
