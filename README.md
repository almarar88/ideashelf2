# نخيلي — تطبيق إدارة مزارع النخيل

تطبيق ويب متكامل لإدارة مزرعة نخيل: عدد النخيل ومتابعة كل نخلة بملف مستقل،
العمال والرواتب، المصاريف، تقويم زراعي موحد، خرائط لموقع المزرعة وكل نخلة،
كشف أمراض النخيل بالذكاء الاصطناعي، توثيق بالصور، وسوق لبيع وشراء
ومزايدة على الفسائل والنخيل.

## المكدس التقني

- Next.js (App Router) + TypeScript + Tailwind CSS
- Prisma + SQLite لقاعدة البيانات
- Leaflet / react-leaflet للخرائط (بلاطات OpenStreetMap المجانية)
- Recharts للرسوم البيانية
- Open-Meteo لبيانات الطقس (بدون مفتاح API)
- Anthropic API (اختياري) لتحليل صور أمراض النخيل بالذكاء الاصطناعي، مع
  محلل احتياطي مبني على قاعدة معرفة بالأمراض الشائعة عند عدم توفر مفتاح API

## التشغيل محليًا

```bash
npm install
cp .env.example .env   # عدّل القيم حسب الحاجة
npx prisma migrate deploy
npx prisma db seed     # بيانات تجريبية (مزرعة + 36 نخلة + عمال + مصاريف...)
npm run dev
```

افتح http://localhost:3000 وسجّل الدخول بالحساب الافتراضي:
`owner@farm.local` / القيمة الموجودة في `OWNER_PASSWORD` بملف `.env`.

## المزايا الرئيسية

- **النخيل**: قائمة/خريطة بكل النخيل، ملف مستقل لكل نخلة (الصنف، الموقع،
  الارتفاع، الإنتاجية، الحالة، معرض صور، سجل تشخيصات).
- **خريطة المزرعة**: تحديد موقع المزرعة ومساحتها، وعرض توزيع النخيل عليها.
- **كشف الأمراض بالذكاء الاصطناعي**: رفع صورة سعف/جذع/ثمار، تحليلها وإرجاع
  اسم المرض، درجة الثقة، الأعراض، طريقة العلاج ونصائح الوقاية. يعمل بمفتاح
  `ANTHROPIC_API_KEY` (نموذج Claude برؤية الصور) أو بمحلل احتياطي بدون اتصال.
- **العمال والرواتب**: بيانات العمال، سجل رواتب شهري، تسجيل الدفع.
- **المصاريف والتقويم**: تسجيل المصاريف حسب الفئة، وتقويم موحد يجمع
  المصاريف والرواتب المستحقة ومهام الري/التسميد/الرش/الحصاد.
- **السوق**: إعلانات بيع/شراء فسائل مع صور وسعر وتواصل.
- **المزادات**: إنشاء مزاد بسعر ابتدائي ومهلة زمنية، تقديم مزايدات حية،
  واحتساب الفائز تلقائيًا عند الانتهاء.
- **لوحة تحكم**: إحصاءات عامة، حالة الطقس الحالية للمزرعة، رسوم بيانية
  لتوزيع حالة النخيل والمصاريف حسب الفئة، والمستحقات القادمة.

## ملاحظات

- بدون `ANTHROPIC_API_KEY` يعمل كشف الأمراض بمحلل احتياطي يعتمد على قاعدة
  معرفة بأشهر أمراض وآفات نخيل التمر (سوسة النخيل الحمراء، الدوباس، تعفن
  الطلع والقمة النامية، نقص العناصر...) لأغراض العرض التوضيحي فقط، وليس
  بديلاً عن استشارة مختص وقاية نباتية.
- الصور المرفوعة تُخزّن في `public/uploads` على القرص المحلي.
